# 📇 Contact App

## 🚀 Overview
The **Contact App** is a simple yet powerful contact management system built with **React.js** and **Firebase**. It allows users to efficiently add, update, delete, and search contacts while ensuring real-time data updates with Firebase Firestore. The application is styled with **Tailwind CSS**, providing a sleek and responsive user experience.

## 🎯 Features
- 📌 **Add, Update & Delete Contacts** – Easily manage your contact list.
- 🔍 **Search Functionality** – Quickly find contacts with a search bar.
- 📡 **Real-time Database** – Instant updates using Firebase Firestore.
- 📱 **Responsive UI** – Optimized for both desktop and mobile users.
- 🎨 **Modern Design** – Styled with Tailwind CSS for a sleek and intuitive layout.

## 🛠️ Technologies Used
- **React.js** – Frontend framework for building interactive UI.
- **Firebase Firestore** – NoSQL cloud database for real-time data handling.
- **Tailwind CSS** – Utility-first CSS framework for modern styling.
- **React Hooks** – Efficient state management and side effects handling.

## 📦 Installation & Usage
1. Clone the repository:
   ```bash
   git clone https://github.com/Starlord00788/FireBase-Contact-App.git
   ```
2. Navigate to the project folder:
   ```bash
   cd FireBase-Contact-App
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Set up Firebase:
   - Create a Firebase project.
   - Add your Firebase configuration in a `.env` file.
   - Enable Firestore Database.
5. Start the development server:
   ```bash
   npm run dev
   ```
6. Open your browser and visit:
   ```
   http://localhost:3000
   ```
7. Start managing your contacts efficiently! 📞
